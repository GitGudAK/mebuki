Niwa

How Niwa is built

A free iPhone app for keeping plants alive.

Animation engine

Every animation in Niwa is drawn by a small open-source engine that lives in the app's own codebase (src/motion). It does not use a third-party animation library.

  • React + SVG. Each scene is a React component that draws vector shapes and reads the current frame, so artwork stays sharp at any screen size.
  • Frame clock and timeline. Sequence and Series place scenes on a 30 fps timeline; the player renders in-between frames, so motion runs at the display's full refresh rate (up to 120 Hz).
  • Motion primitives. Physically based springs, interpolate with easing curves, and seeded randomness keep every frame deterministic.

The rest of the stack

  • Capacitor runs the app natively on iPhone, fully offline, with everything bundled.
  • Vite and TypeScript build the app.
  • Playwright and ffmpeg render the same scenes frame by frame to MP4 for sharing.

The source code is public at github.com/GitGudAK/niwa.
